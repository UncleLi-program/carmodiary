Crystal Orb Dock — Visual Specification

Dock 视觉规范

本规范定义车模志底部导航（悬浮玻璃 Dock）的尺寸、色彩、圆角、阴影、动效与响应式刻度。 核心目标是让「选中轨道」与「扫码入库键」在同一套设计语言下各自成立： 一个宽 pill 负责指示，一个近方形按键负责动作，任何宽度下四个元素严格等距。

概览

Dock 由「玻璃容器 + 选中轨道 + 3 个 Tab + 1 个动作键 + 长按提示」构成，全部刻度集中在一处定义。

ANATOMY

五层结构

容器玻璃（blur + 冷调 tint）→ 颗粒噪点（soft-light）→ 选中轨道（z1）→ Tab / 动作键（z2）→ Peek 提示（z5）。

HIERARCHY

一颗蓝色主体

选中轨道是宽 74px 的 pill，扫码键是 46px 的近方形；同色系但不同形状与宽度，保证同一时刻只有一个视觉指示器。

RHYTHM

四等分

容器内容区被 4 个 flex:1 槽位等分，圆心距在 342 / 316 / 280px 三种宽度下分别为 81 / 75.5 / 66.5px。

MATERIAL

玻璃而非贴纸

层级只靠内高光与冷调投影表达，不使用白色描边环；动作键通过中性投影与轨道拉开距离。

01

设计原则

四条原则用于判断后续改动是否“仍然像这套 Dock”。

P-01

单一蓝色主体

蓝色只表达两种语义：选中（轨道）与核心动作（扫码键）。不得再引入第三种蓝、第二种渐变方向或第二个等高 pill。

P-02

等宽节奏

四个槽位始终等分。Tab 的左右 padding 必须为 0——在 box-sizing:border-box 下，横向 padding 会让 flex 基准多出 8px，直接破坏等距。

P-03

同族圆角

22（容器）→ 16（轨道）→ 15（动作键）。元素越小，圆角越小，形成同心收缩关系；禁止出现 6px 这类跳出刻度的圆角。

P-04

光影分层

分离层级只用两件事：顶部 1px 内高光 + 同方向的冷调负偏移投影。不要加描边、发光边框或锥形旋转弧。

结构与网格

容器内容区 = 4 个等宽槽位。轨道与动作键都在各自槽位内居中，轨道位置由 JS 运行时测量。

示意图按 342px 容器绘制（8px 内边距 + 1px 边框），每个槽位 81px。槽位内部元素：轨道 74px（左右各留 3.5px），动作键 46px（左右各留 17.5px）。

光学对齐OPTICS

  • 动作键中线 = Tab 图标中线：按键 46px、抬升 10px，其中心 y≈22px；Tab 图标中心 y≈22.8px，误差 ≤1px。
  • 轨道与 Tab 同心：轨道 46px 高，覆盖图标 + 文字行框；文字行框底距轨道下缘约 1.8px，字形视觉留白约 5px。
  • 动作键抬升上限：抬升超过 12px 会让按键顶部突出容器边界，破坏“嵌在玻璃里”的观感。

响应式

只缩尺寸，不改结构：槽位数量、圆角族关系、色阶与对齐规则在所有断点保持一致。

断点容器轨道按键Tab图标
默认（>360px） 64h · r22 · pad 8 · 侧边 14 74 × 46 · r16 46 · r15 · -10 11px · pad 7 0 · gap 3 22 / 21
≤360px 60h · r20 · pad 6 · 侧边 10 66 × 42 · r14 42 · r13 · -8 10.5px · pad 6 0 · gap 2 21 / 19
  • 缩放系数约 0.9：每个断点都保持“轨道宽 = 槽位宽 - 7px、按键 = 轨道高 - 4px”的关系。
  • 切换断点后必须重新测量轨道位置（resize → moveOrb()），否则轨道会停在旧中心。
  • ≤360px 时只允许压缩内边距与字号，不得隐藏文字或把动作键压进 Tab 槽位。

验收清单

每次改动 Dock 后逐项核对；任一项失败即视为回归。

  • 四等分成立 — 342 / 316 / 280px 三档下，圆心距分别为 81 / 75.5 / 66.5，误差 ≤0.5px。
  • 单一蓝色主体 — 同屏只有一颗 74px pill 与一颗 46px 方形按键，无第三种蓝色色块。
  • 光学对齐 — 扫码键中心与 Tab 图标中心高度差 ≤1px；文字字形距轨道下缘 ≥4px。
  • 圆角族未被破坏 — 容器 22 / 轨道 16 / 按键 15；焦点态仍为 15。
  • 深浅两套材质 — 深色下无白色描边残留，投影为深色而非蓝色发光。
  • 功能入口不变 — 3 个 Tab + 扫码入口；点击「+」进入拍照识别，Dock 随之隐藏。
  • 轨道跟随 — 切换 Tab、窗口 resize 后轨道中心与选中 Tab 中心误差 <2px。
  • 键盘可用 — 聚焦扫码键后 Enter / Space 可打开相机；焦点环不改变按键圆角。
  • 减弱动效 — 开启 reduce 后无位移、无呼吸、无掠光，仍保留全部静态样式。
  • 无脚本报错 — 从加载到连续切换页面，控制台无 error。
