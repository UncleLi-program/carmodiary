一、审计口径 本项目「视角」= 用户在每个页面看到的同一套空间与交互基准

本次从五个维度逐一核对：导航视角（层级与返回落点）、布局视角（页头 / 留白 / 底部基线）、组件视角（卡片 / 列表 / 空态 / 反馈的规格）、图像视角（裁切锚点与比例）、明暗视角（状态栏与深色界面规则）。Dock 栏遵循 v2 冻结规范，仅核对其显隐逻辑，不参与改造。

V1页面层级与转场

一级页 base 淡入；二级页 push 统一自右向左 translateX(103%)。Dock 仅在一级页显示，规则已统一。

V2页头与留白

导航栏 56px 顶部内边距、返回区 84×34、标题 16.5px；页面左右留白 16px；卡片间距 12–14px。

V3组件规格

卡片圆角 18、列表行 12、主按钮胶囊形、开关 44×27；同一语义的组件应有同一规格与同一反馈。

V4图像取景

1:1 车模缩略图统一 object-position:center 35%；壁纸 16:9；详情 hero 使用独立取景锚点但需与卡片方向一致。

V5明暗视角

仅「拍照 / 详情」允许深色页头；状态栏图标颜色必须随页头明暗切换，且由页面声明，而不是写死在某个页面 id。

V6底部基线

一级页为 Dock 预留 112px；二级页 Dock 隐藏，底部只保留 24–32px 安全留白，不继承 Dock 高度。

三、P0 · 阻断一致体验的问题 优先修正，影响用户对「同一款应用」的感知

P0-1详情页状态栏未反色，深色页头下图标几乎不可见详情页

现象

拍照页会把状态栏切成白色，但进入车模详情页后，状态栏又回到深色文字；详情页顶部是深色车图 + 黑色渐变蒙层，时间、信号、电量与背景混在一起。同一「深色页头」在不同页面得到两种状态栏结果。

证据

状态栏切换只判断 camera：index.html#L1730
详情页 hero 深色图直接顶到顶部：#L343-L345
详情页导航栏为绝对定位深色玻璃：#L1283-L1287
修正方向：把「状态栏明暗」从页面 id 判断改为页面主题声明（如 screens 元数据增加 status:'light'，或为详情页根节点加 data-status="light"），详情页与拍照页共用同一规则；同时确认导航栏顶部 52px 区域的渐变不透明度足以承载白色状态栏。
P0-2Dock 隐藏页仍沿用 Dock 高度的底部留白，出现四种基线图鉴 / 我想要 / 结果 / 设置系列 / 详情

现象

二级页 Dock 已经隐藏，但底部仍按「有 Dock」预留空间：图鉴滚动到底空出约 130px，我想要 112px，识别结果 104px，设置类页面仅 24–30px，详情 40px。同为「无 Dock」状态，底部收尾相差最多 106px，长页面会显得断裂。

证据

图鉴：#L698（30px）+ #L723（100px）
我想要：#L866（112px）
识别结果：#L339（104px）
设置页脚：#L1024（30px）；详情：#L351（40px）
修正方向：拆出两个底部基线——一级页使用 --dock-clear:112px，二级页统一使用 24–32px 的安全留白；图鉴的 .g-note 100px、我想要 112px、结果 104px 全部改归二级页基线，避免继续叠加。
P0-3同一入口存在不同返回落点，用户无法预测「后退去哪」拍照 / 结果 / 我想要 / 设置系列

现象

从 Dock 进入拍照会保留来源 Tab（日历进 → 回日历），从左侧步骤面板进入却固定回首页；收藏入库后无论从哪进入都跳回首页；「我想要」从我的进入回我的，从图鉴/详情进入则回上一层。设置系列不在左侧步骤面板中，进入后面板没有任何高亮，当前「位置视角」丢失。

证据

Dock 入口保留来源：#L2260
面板入口固定首页：#L2223-L2226
收藏入库固定回首页：#L1843
我想要直接入栈：#L2279
无匹配步骤时不高亮：#L2238
修正方向：建立「入口即来源」规则：所有二级页记录 entryOrigin，返回与流程结束都回来源页；拍照完成改为回 origin（日历进则回日历）；「我想要」从面板进入前先归一到 home；设置系列在左侧面板增加「设置」步骤或映射到「我的」，保证任何页面都有位置反馈。
P0-4同一张车图在四个页面裁切方向不同，car 头位置漂移我想要 / 详情

现象

首页与图鉴卡片统一把取景锚点上移到 35%，车头稳定出现在画面上方；「我想要」卡片与详情 hero 使用默认居中裁切，同一素材从收藏库进入想要页或详情页时，车头位置明显下移、车顶留白变多，形成「换了视角」的错觉。

证据

首页/图鉴统一 35%：#L182-L185
我想要未声明锚点：#L874
详情 hero 未声明锚点：#L344
修正方向：抽出共享媒体规则（如 .ph img / .media img { object-position:center 35% }）；详情 hero 使用独立但明确的锚点（建议 center 42%），并在规范中记录「缩略图 35% / hero 42% / 壁纸 50%」三档，避免继续散落。

四、P1 · 明显规格偏差 不阻断流程，但会被用户感知为「不齐」

P1-1「我想要」卡片没有 hover / 按下反馈我想要

现象

首页与图鉴卡片有悬浮抬升和按下缩放，我想要卡片只有光标手型，点击时没有任何形变；从首页进入想要页后，同一张卡片的操作手感突然变「硬」。

证据

首页卡片 hover / active：#L170-L176
我想要卡片无对应态：#L867-L884
修正方向：将卡片按压反馈抽为共用类（如 .pressable），三处网格卡片统一 translateY(-3px) 悬浮与 scale(.965) 按下。
P1-2「我的」与「设置」列表行基准不一致我的 / 设置

现象

我的列表行内边距 13×14、图标 34px；设置行 12×16、图标 32px。两页互相跳转时，左侧图标与文字整体错位 2px，右箭头也随之偏移，视觉上像两套组件。

证据

我的行：#L834-L849
设置行：#L917-L928
修正方向：合并为同一个列表行规格（建议 13px 16px、图标 32、圆角 10），两页共用 class 或 CSS 变量。
P1-3区块标题存在 11.5 / 11 / 10.5 三档字号结果 / 详情 / 设置系列 / 图鉴

现象

结果与详情使用 11.5px 的 .sec h5；设置系列使用 11px 的 .sc-head；图鉴说明、日历说明使用 10.5px。同级信息在跨页时字号与字色不一致，标题层级被削弱。

证据

.sec h5：#L306-L311
.sc-head：#L907-L914
.g-note：#L723
修正方向：固化三级文字：区块标题 11.5/600/--sub，说明文字 10.5/--faint，徽标 10；设置页标题向 11.5 靠拢，图鉴说明保持 caption 级。
P1-4页面首个内容块的顶部间距在 10 / 12 / 14 / 16 之间跳动首页 / 图鉴 / 我的 / 我想要 / 设置系列

现象

首页大数字 14px、图鉴卡 12px、我的头部 10px、我想要说明卡 10px、设置卡 12px、日历汇总 16px。切换 Tab 时首个卡片的下沿不在同一水平线，页面「重心」上下浮动。

证据

.h-entry：#L619（10px）
.g-top：#L643（12px）
.me-head / .w-top：#L859（10px）
.cal-sum：#L228（16px）
修正方向：统一页面首块 margin-top:12px，Tab 页可保留 10px 的紧凑感但需写成变量；避免以「元素类型」决定间距。
P1-5空状态有三套视觉语言我想要 / 通知提醒 / 图鉴

现象

我想要：40px 图标 + 12px 说明 + 主按钮；通知提醒：32px 图标 + 12.5px 标题 + 10.5px 说明，无操作；图鉴搜索为空：30px 图标 + 行高 2 的说明。图标尺寸、文案层级、是否有 CTA 全部不同。

证据

.w-empty：#L886-L896
.set-empty：#L1004-L1012
.g-empty：#L721-L722
修正方向：抽出统一 .empty-state：图标 32、标题 12.5/700、说明 10.5/1.65、可选主按钮（仅当有明确下一步时出现）。
P1-6「想要」同时使用粉色、紫色与粉紫渐变，语义色不统一我的 / 我想要 / 详情

现象

我的页统计数字用粉色，我想要页顶部标题与标签用紫色，卡片角标与详情按钮用粉紫渐变；同一功能出现三种主色，用户难以把「想要」与固定色建立映射。

证据

粉色统计：#L828
紫色说明与标签：#L860-L865
渐变按钮 / 角标：#L741-L746
修正方向：定义「想要」色组：主作用色=粉紫渐变（按钮/角标），文本强调=#8a4adf，浅底=#fbe6ee；明确禁止在正文标题继续新增第三种粉/紫。
P1-7Toast 固定 118px，在无 Dock 页面悬空设置 / 通知 / 关于 / 详情 / 图鉴 / 我想要

现象

Toast 的 118px 是为 Dock 预留的位置。进入二级页后 Dock 已隐藏，提示仍浮在屏幕中下部，与内容、底部安全区都没有关系，看起来像被「吊」在半空。

证据

Toast 基线：#L756-L761
Dock 隐藏规则：#L1729
修正方向：在 layout() 同步一个 Dock 状态类，Toast 分两档：有 Dock 时 118px，无 Dock 时 calc(28px + env(safe-area-inset-bottom))。

五、P2 · 细节与维护风险 可随下一次改版一并收口

P2-1详情页深色导航栏以内联样式实现，拍照页用 CSS详情 / 拍照

现象

两处深色页头分别由内联 style 与 #scr-camera 选择器维护，胶囊、分割线、返回箭头颜色各写一遍，后续改主题极易漏改。

证据

内联深色：#L1283-L1287
CSS 深色：#L240-L243
修正方向：抽取 .navbar.dark（含背景、标题、返回、胶囊、分割线），两页共用。
P2-2详情 hero 固定 255px 且无取景锚点详情

现象

hero 高度写死 255px，不同屏幕宽度下裁切比例变化；未声明 object-position，车头位置随图片源浮动，与卡片 1:1 的取景语言脱节。

证据

Hero 规格：#L343-L345
修正方向：改用比例约束（如 aspect-ratio:16/10 或按屏宽 clamp），并显式声明 object-position，纳入 V4 图像规范。
P2-3减弱动态只覆盖 Dock，页面转场与卡片动画未覆盖全局

现象

prefers-reduced-motion 只关闭 Dock 的过渡与呼吸动画，二级页横滑、卡片 rise / pop、底部弹层上滑仍然播放，系统性无障碍策略不完整。

证据

现有覆盖：#L610-L615
未覆盖的 push 转场：#L117
修正方向：在 reduced-motion 块内统一关闭 .screen.push、.card、.sheet 的过渡/动画，仅保留透明度变化。
P2-4全局焦点环把组件圆角改成 6px全局

现象

键盘聚焦时，卡片、胶囊按钮的焦点轮廓会变成 6px 圆角，与组件本身的 18px / 20px 圆角不一致，焦点态反而破坏形状语言。

证据

全局焦点规则：#L771-L772
修正方向：只声明 outline，删除统一 border-radius；或按组件继承 border-radius:inherit。
P2-5同步完成后「我的」页的上次同步时间不刷新我的 / 图鉴

现象

同步会更新状态字段，但只重绘图鉴；从我的页触发同步后，该行仍显示旧的「今天 09:41」，同一数据在两个页面出现两个时间视角。

证据

同步逻辑：#L2160-L2173
我的页渲染：#L1951-L1959
修正方向：同步成功后调用 renderProfile()，或抽出单一 renderSyncState() 同时更新两处。
P2-6日历底部 100px 与首页 112px 不一致日历 / 首页

现象

同为带 Dock 的一级页，首页为 Dock 预留 112px，日历说明只留 100px，滚到底时文字与 Dock 的间距相差 12px。

证据

首页 112px：#L165
日历 100px：#L236
修正方向：一级页统一引用 --dock-clear，日历说明改为同一变量。

六、保留的设计例外 建议写入规范，而不是强行统一

拍照页纯黑取景：唯一无卡片、无浅色底的沉浸界面，深色规则应复用组件而非改成浅色。
详情页沉浸式 hero：允许绝对定位导航与空标题，但状态栏与取景锚点必须纳入统一规则。
设置文档使用底部弹层：与全屏 push 形成「内容页横滑 / 辅助信息上滑」两类方向，是有意分层，不需要改成全屏。
弹层无关闭按钮：仅遮罩关闭，已在三种屏幕尺寸验证，不在本次不一致范围内。
Dock v2：4 等分槽位、74×46 轨道、46×46 扫码键为冻结规范，本报告只核对显隐，不提出视觉修改。

七、修正路线 建议按批次执行，避免一次性重排

第一批 · P0 体验一致性

  • 状态栏主题化：详情页接入 light 规则
  • 底部基线拆分：一级 112 / 二级 24–32
  • 入口来源统一：拍照、想要、设置返回落点
  • 图像锚点：共享 35%，hero 42%

第二批 · P1 组件收口

  • 卡片反馈统一为 .pressable
  • 列表行统一 13×16 / 32px 图标
  • 区块标题统一 11.5 / 10.5 两档
  • 空状态统一 .empty-state
  • 「想要」色组固定；Toast 分档

第三批 · P2 维护性

  • 抽 .navbar.dark 与 hero 比例约束
  • 补全 reduced-motion 覆盖
  • 修正焦点环圆角
  • 同步状态单一数据源
  • 日历底部对齐 112px

八、修正后的验收清单 逐项可复核

任意入口进入拍照并完成入库后，返回的是进入前的来源页，而不是固定首页。
在首页、图鉴、我想要、详情四处查看同一台车，车头在画面中的相对高度一致。
所有二级页滚动到底，最后一块内容与屏幕底部的距离落在 24–32px，不出现 100px 以上空档。
详情页状态栏为白色，离开详情后恢复深色，且不依赖页面 id 的硬编码判断。
我的与设置互相跳转时，列表图标左边缘、文字基线、箭头位置完全对齐。
三种屏幕尺寸下，底部弹层仍只能通过遮罩关闭，点击内容区与标题栏不关闭。
开启「减弱动态效果」后，页面横滑、卡片入场、弹层上滑均降级为淡入。
从图鉴同步后回到我的页，「上次同步」显示为刚刚，而不是旧时间。
